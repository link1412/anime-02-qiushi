# SFX sources: lighter, exhale, and cigarette drag (CC0 only)

Checked 2026-10-30. I checked the license on each sound's own page and downloaded only sounds shown as CC0.
- Freesound: the license box shows "Creative Commons 0" and links to http://creativecommons.org/publicdomain/zero/1.0/.
- BigSoundBank: the page's License heading reads "CC0 (public domain): Free and royalty-free".

Freesound originals require a login, so the Freesound files here are the public HQ previews (128 kbps MP3).
BigSoundBank files are the site's public FLAC downloads (lossless, 48 kHz/24-bit originals; that site's WAV path returns 403 to curl).
